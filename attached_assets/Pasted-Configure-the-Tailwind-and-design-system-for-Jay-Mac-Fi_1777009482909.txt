Configure the Tailwind and design system for Jay Mac Fitness before building any UI. This config will be used by every component.

In tailwind.config.js, extend the theme:
colors:
  navy: { DEFAULT: '#0D1B2A', dark: '#0A1628', mid: '#112240', steel: '#1A3A5C' }
  blue: { DEFAULT: '#1E90FF', soft: '#4DAAFF', glow: 'rgba(30,144,255,0.15)' }
  offwhite: '#C8D8E8'

In index.html (client/index.html):
- Add Google Fonts import in <head>:
  <link rel="preconnect" href="https://fonts.googleapis.com">
  <link rel="preconnect" href="https://fonts.gstatic.com" crossorigin>
  <link href="https://fonts.googleapis.com/css2?family=Barlow+Condensed:ital,wght@1,900&family=Barlow:wght@400;600;700&family=Inter:wght@400;500&display=swap" rel="stylesheet">
- Set page title: Jay Mac Fitness — Achieve Your Goals

Set up a scrollReveal.js utility in /client/src/utils/:
- Uses IntersectionObserver to add class 'visible' to any element with class 'reveal'
- Runs once on mount (do not repeat on scroll back up)
- Stagger delay applied via inline style delay on nth-child when elements are in a grid

Import scrollReveal in App.jsx and run on mount.
